# НАОМ Платформа — Инструкция по обновлению данных

---

## 📁 Структура проекта

```
naom-platform/
├── index.html          ← Страница мероприятий
├── contractors.html    ← Страница подрядчиков
├── styles.css          ← Стили (не трогать)
├── app.js              ← Логика (не трогать)
└── data/
    ├── events.js       ← ВСЕ МЕРОПРИЯТИЯ — редактируй здесь
    └── contractors.js  ← ВСЕ ПОДРЯДЧИКИ — редактируй здесь
```

---

## ✏️ Как добавить новое мероприятие

1. Открой файл `data/events.js`
2. Найди нужный месяц (они идут по порядку)
3. Добавь новый блок перед закрывающей `];`:

```js
{
  id: 66,                          // Следующий по порядку номер
  title: "Название мероприятия",   // Обязательно
  date: "14-15 апреля",            // Обязательно
  month: "apr-2026",               // Обязательно (см. коды ниже)
  city: "moscow",                  // Обязательно (см. значения ниже)
  importance: "medium",            // Обязательно: high / medium / low

  // Необязательные поля:
  description: "Краткое описание мероприятия.",
  recommended: "1-2 человека",
  link: "https://example.com",
  naom_participation: "БЕСПЛАТНО",
  is_featured: true,               // true = показывать в Топ событий
  tags: ["ивент", "MICE"],
  type: "forum"                    // conference / forum / festival / award / webinar
},
```

### Коды месяцев:

| Месяц       | Код        |
| ----------- | ---------- |
| Январь 2026 | `jan-2026` |
| Февраль     | `feb-2026` |
| Март        | `mar-2026` |
| Апрель      | `apr-2026` |
| Май         | `may-2026` |
| Июнь        | `jun-2026` |
| Июль        | `jul-2026` |
| Август      | `aug-2026` |
| Сентябрь    | `sep-2026` |
| Октябрь     | `oct-2026` |
| Ноябрь      | `nov-2026` |
| Декабрь     | `dec-2026` |

### Значения city:

- `moscow` — Москва
- `spb` — Санкт-Петербург
- `russia-other` — Другие города России
- `online` — Онлайн
- `international` — Зарубежье

### Значения importance:

- `high` — Обязательно (красная полоска)
- `medium` — Рекомендуется (оранжевая)
- `low` — По возможности (зелёная)

## ✏️ Как добавить нового подрядчика

1. Открой файл `data/contractors.js`
2. Найди нужную категорию
3. Добавь новый блок:

```js
{
  id: 31,                          // Следующий по порядку
  name: "Название компании / Имя", // Обязательно
  category: "host",                // Обязательно (см. категории ниже)

  // Необязательные поля:
  description: "Описание и специализация.",
  price: "150 000 руб.",
  website: "https://example.com",
  experience: "10 лет, 500 мероприятий",
  clients: "Газпром, Яндекс, Сбербанк",
  highlights: [
    "Первое ключевое преимущество",
    "Второе ключевое преимущество"
  ],
  city: "moscow",
  tags: ["корпоратив", "юмор"]
},
```

### Категории подрядчиков:

| Категория        | Код            |
| ---------------- | -------------- |
| Ведущие          | `host`         |
| Кавер-группы     | `band`         |
| Шоу              | `show`         |
| Лофты            | `venue-loft`   |
| Рестораны        | `venue-rest`   |
| Дворцы/Усадьбы   | `venue-palace` |
| Арт-пространства | `venue-art`    |
| Интерактив       | `interactive`  |

---

### Обновление данных:

1. Отредактируй `data/events.js` или `data/contractors.js`
2. Зайди в репозиторий на GitHub
3. Нажми на нужный файл → иконку карандаша (Edit)
4. Вставь изменения → нажми **Commit changes**
5. Сайт обновится автоматически через 1-2 минуты

## 🔧 Локальный запуск (для проверки)

**Вариант 1 — через VS Code:**

- Установи расширение **Live Server**
- Открой папку проекта → правой кнопкой на `index.html` → **Open with Live Server**

**Вариант 2 — через Python:**

```bash
cd naom-platform
python3 -m http.server 8000
# Открой http://localhost:8000
```

**Вариант 3 — просто открыть файл:**

- Двойной клик на `index.html` — откроется в браузере
- ⚠️ Некоторые браузеры блокируют JS при открытии через `file://` — тогда используй Live Server

## ❓ Частые вопросы

**Как добавить Топ-событие?**
Добавь поле `is_featured: true` в карточку мероприятия.

**Как убрать мероприятие из списка, но не удалять?**
Добавь поле `hidden: true` — и оно перестанет отображаться (если логика это поддерживает), или просто удали блок.

**Что будет, если я забуду запятую между записями?**
Страница перестанет работать. Всегда проверяй, что после закрывающей `}` стоит `,` (кроме последней записи).

**Как сохранить изменения локально?**
Просто сохрани файл (Ctrl+S / Cmd+S) — браузер подхватит изменения при перезагрузке страницы.
